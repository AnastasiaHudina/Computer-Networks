# Лабораторная работа №1. Протоколы ARQ: Go-Back-N и Selective Repeat

Реализация имитационной модели двух протоколов автоматического запроса повторной
передачи (Automatic Repeat reQuest, ARQ) — **Go-Back-N (GBN)** и
**Selective Repeat (SR)** — в условиях канала с потерями пакетов.

Работа выполнена в рамках курса «Компьютерные сети»
(Физико-механический институт, ВШПМиВФ).

## Возможности

- Имитация ненадёжного канала связи с задаваемой вероятностью потерь DATA-пакетов.
- Возможность отдельно задавать вероятность потерь ACK (по умолчанию ACK надёжны,
  что согласуется с аналитической моделью).
- Реализация двух протоколов: Go-Back-N и Selective Repeat.
- Настраиваемый размер скользящего окна.
- Настраиваемый тайм-аут ожидания подтверждения.
- Автоматический перебор параметров эксперимента и усреднение результатов.
- Сохранение результатов в CSV.
- Построение графиков накладных расходов `H(p)`, коэффициента эффективности `k(p)`
  и времени передачи `t(p)` для разных размеров окна.

## Метрики

**Накладные расходы** (основная метрика):

```
H = (total_sent - total_packets) / total_packets * 100%
```

Доля «лишних» (повторных) передач относительно полезных. Чем меньше `H`,
тем эффективнее протокол.

**Коэффициент эффективности:**

```
k = total_packets / total_sent = 1 / (1 + H / 100)
```

Доля полезных передач. Связан с `H` линейно.

**Время передачи** `t` (в секундах) — от начала передачи до получения
подтверждения на последний пакет. Зависит от машины, поэтому носит
вспомогательный характер.

## Теоретические формулы

Для проверки корректности реализации графики `H(p)` сравниваются
с аналитическими зависимостями:

- **Selective Repeat:** `H_SR = 100 · p / (1 - p) %`,
  не зависит от размера окна `W`.
- **Go-Back-N:** `H_GBN ≈ 100 · (W / E[X] - 1) %`,
  где `E[X] = q · (1 - q^W) / p`, `q = 1 - p`.

При `W = 1` оба протокола вырождаются в Stop-and-Wait и дают одинаковые
накладные расходы.

## Ожидаемые результаты

- При `p = 0` оба протокола дают `H = 0`, `k = 1`.
- С ростом `p` накладные расходы растут у обоих протоколов.
- Для Selective Repeat `H` практически не зависит от `W`.
- Для Go-Back-N `H` растёт и с `p`, и с `W`: ошибка ближе к началу
  большого окна делает бесполезными все последующие передачи.
- При `W = 1` оба протокола совпадают.
- При больших `p` и `W` Selective Repeat существенно эффективнее
  Go-Back-N.

## Полученные результаты

- При `p = 0.30` и `W = 8` накладные расходы составляют около 42% для SR.
- При тех же параметрах накладные расходы для GBN составляют около 348%.
- SR эффективнее GBN по накладным расходам почти в 8 раз при `p = 0.30` и `W = 8` (42 % против 348 %); по коэффициенту эффективности `k` выигрыш превышает 3× (0.71 против 0.22).
- Для SR значения `H` при разных `W` лежат в диапазоне 40.9–42.7%.
- Эти значения совпадают с теоретической оценкой `H_SR = 100 p / (1 - p)` в пределах доверительных интервалов.
- Для GBN наблюдается систематическое превышение экспериментальных значений над теоретическими (в 1.3–1.7 раза).
- Это объясняется различием между раундовой моделью, использованной при выводе формулы, и непрерывной моделью передачи, реализованной в имитации.
